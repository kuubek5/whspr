# 🎙️ KuubWave — простими словами

> [!info] Що це
> Програма для **голосової диктовки** на Windows. Затиснув клавішу — говориш —
> відпустив — текст сам зʼявляється там, де стоїть курсор (у будь-якій програмі).
> Усе рахується **локально на твоєму ПК**, нічого не йде в інтернет.

---

## Як користуватись

1. Затисни **F9** (клавішу можна змінити).
2. Говори українською або англійською.
3. Відпусти клавішу.
4. Текст автоматично вставляється у вікно, де ти був.

Збоку внизу екрана — маленька плашка показує стан: *Запис → Розпізнаю → готово*.

## 💳 Як продавати (ліцензія)

> [!tip] Модель — підписка на місяць
> Ти видаєш клієнту **ключ на 30 днів**. Через місяць програма просить новий ключ.

**Ти (продавець) видаєш ключ однією командою:**
```
python make_license.py issue --days 30 --id "пошта_клієнта"
```
Програма надрукує довгий ключ — надсилаєш його клієнту.

**Клієнт:** вставляє ключ у **Налаштування → Ліцензія → Активувати**.

Поки ключа нема або він прострочений — диктовка не працює, програма просить ключ.

> [!warning] 🔴 Найважливіше — бекап приватного ключа
> Файл `keys\whspr_ed25519.pem` — це твій **секретний ключ**, яким підписуються
> усі ліцензії. Він зберігається лише на твоєму компʼютері (в git не потрапляє).
> **Зроби копію в надійне місце** (менеджер паролів / зашифрований диск).
> Втратиш його — не зможеш видавати нові ключі до вже проданих копій.

> [!note] Чесно про захист
> Це «замок від чесних людей»: зупиняє звичайний шеринг і тримає місячний строк.
> Досвідчений хакер із файлом програми теоретично може обійти — так у **будь-якої**
> офлайн-програми. Для серйозного захисту пізніше можна додати привʼязку до ПК
> або онлайн-перевірку.

## 📦 Як зробити інсталятор

Коротко (деталі — у [[packaging/README]]):

```powershell
# 1. зібрати програму
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Отримаєш `kuubwave-setup.exe` (~270 МБ). Інсталятор **легкий**, бо важке
докачується при першому запуску:

| Що | В інсталяторі | Качається при 1-му запуску |
|----|:---:|:---:|
| Сама програма | ✅ | |
| Модель розпізнавання (~1.5 ГБ) | | ✅ |
| Драйвери відеокарти CUDA (~0.9 ГБ) | | ✅ (лише якщо є NVIDIA) |

> [!info] Де лежать дані користувача
> Конфіг, історія, моделі, ліцензія — у `%LOCALAPPDATA%\KuubWave`.
> Сама програма в Program Files лишається незмінною.

## 🧩 З чого складається (технічно, коротко)

- `flow.py` — мозок: запис звуку, розпізнавання, вставка тексту, гарячі клавіші.
- `web/` — інтерфейс (вікно програми).
- `webview_app.py` — містить вікно та звʼязує інтерфейс із мозком.
- `ui.py` — плашка-індикатор внизу екрана.
- `licensing.py` + `make_license.py` — перевірка та випуск ключів.
- `cuda_setup.py` — докачування драйверів відеокарти.
- `packaging/` — як зібрати інсталятор.
