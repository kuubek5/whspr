# Architecture

## Пайплайн

```
Хоткей (hold-to-talk)
  → sounddevice запис 16 кГц моно (+ pre-roll 500 мс кільцевий буфер)
  → RMS-гейт тиші (відкинути порожнє)
  → faster-whisper (CTranslate2, int8, на CUDA) + initial_prompt (uk)
  → фільтр галюцинацій
  → [опційно] LLM-полішинг (Groq / Ollama)
  → голосові команди (replacements) + автокапіталізація
  → запис у history.db (SQLite)
  → вставка: буфер обміну + Ctrl+V (фізична VK 0x56)
  → пігулка-індикатор + оновлення статистики
```

## Модулі

| Файл | Роль |
|---|---|
| `flow.py` | ядро: аудіо, модель, хоткеї, вставка, пайплайн, трей, `AppContext` |
| `app_gui.py` | головне вікно (customtkinter), відв'язане через `AppContext` |
| `ui.py` | плаваюча пігулка-індикатор (чистий tkinter, потокобезпечна) |
| `make_shortcut.py` | генератор `whspr.lnk` |

`AppContext` — міст: GUI не знає про внутрішній стан ядра, лише кличе методи
(`status()`, `history_stats()`, `capture_hotkey()`, `save_config()`…). Статус
GUI полінгує щосекунди.

## Ключові технічні рішення

### Вставка через фізичну VK 0x56
`pynput.press('v')` шле **символ** `v`, який Windows мапить через активну
розкладку. На кириличній розкладці `v` не існує (`VkKeyScan → 0xFF`) → Ctrl+V
мовчки не спрацьовує. Рішення — фізична клавіша `KeyCode.from_vk(0x56)`,
незалежна від розкладки. Той самий принцип — для хоткеїв.

### Без Silero VAD
`import onnxruntime` на тестовій машині висить хвилинами (через це «транскрипція»
займала 20 хв). Замість VAD — дешевий RMS-гейт тиші; push-to-talk і так гарантує
мовлення в записі. Whisper викликається з `vad_filter=False`.

### Pre-roll буфер
Кільцевий буфер (`deque`) постійно пише останні 500 мс аудіо ще до натискання
клавіші. Так перше слово не обрізається через реакцію людини.

### Цільове вікно
`GetForegroundWindow()` запам'ятовується в момент відпускання клавіші. Якщо
фокус «втече» під час транскрипції (alt-tab), перед вставкою повертаємось до
потрібного вікна; якщо не вдалось — текст лишається в буфері (не втрачається).

### CUDA без Toolkit
`nvidia-cublas-cu12` / `nvidia-cudnn-cu12` ставляться як pip-колеса; шляхи до
їхніх DLL додаються в `flow.py` через `os.add_dll_directory`. Системний CUDA
Toolkit не потрібен.

### Модель
`deepdml/faster-whisper-large-v3-turbo-ct2` — робоче CT2-дзеркало (оригінальне
`Systran/...` репо на HuggingFace тепер віддає 401). Кешується в
`~/.cache/huggingface/hub`, вантажиться раз.

## Потоки

- **Головний потік:** tk mainloop (GUI) або listener.join() (headless).
- **Аудіо-колбек:** окремий потік sounddevice, пише в буфери.
- **Транскрипція:** щоразу новий daemon-потік (не блокує UI).
- **Хоткеї:** pynput Listener у своєму потоці; рестартабельний при зміні хоткею.

|---|---|
