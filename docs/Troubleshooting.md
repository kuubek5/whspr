# Troubleshooting

## Текст не вставляється

**Причина 1 — розкладка (виправлено в коді):** якщо колись повернеться —
переконайся, що вставка йде через фізичну VK 0x56, а не символ `v`. На
кириличній розкладці символ `v` не мапиться.

**Причина 2 — вікно від адміністратора:** щоб вставляти в програму, запущену
«від імені адміністратора», whspr теж має бути запущений від адміна.

**Причина 3 — фокус втік:** якщо перемкнув вікно під час розпізнавання і
повернення не вдалося — текст лишається в буфері обміну, встав вручну (Ctrl+V).

**Причина 4 — ігри/античіт:** деякі ігри блокують синтетичний ввід.

## `mkl_malloc failed` / pip error 1455

**Pagefile вимкнений.** Commit-ліміт пам'яті = обсяг RAM; коли він заповнений
(багато вкладок браузера тощо), CUDA/pip не можуть виділити пам'ять.

**Фікс:** увімкни pagefile — Win+R → `sysdm.cpl` → Advanced → Performance
Settings → Advanced → Virtual memory → Change → «Automatically manage» → OK →
перезавантаження. Або тимчасово закрий важкі застосунки (браузер).

## Транскрипція триває хвилини

**`import onnxruntime` висить** (Silero VAD). У whspr VAD вимкнено саме через це.
Якщо додаєш VAD назад і стикаєшся — спробуй іншу версію onnxruntime або перевір,
чи Windows Defender не сканує процес у реальному часі.

## `cuBLAS failed` / `CUBLAS_STATUS_EXECUTION_FAILED`

Зазвичай брак VRAM або конфлікт при повторному завантаженні моделей.
- Закрий інші GPU-застосунки (ігри, інший ML).
- Одна модель за раз; не вантаж stock і uk-ft одночасно поспіль у скриптах.
- Тимчасово: `device="cpu"` (повільно, але працює) — прапорець `--cpu` у
  `test_uk_ab.py`.

## Модель не качається (401 / Repository Not Found)

`Systran/faster-whisper-large-v3-turbo` на HuggingFace віддає 401. whspr уже
використовує робоче дзеркало `deepdml/faster-whisper-large-v3-turbo-ct2`. Якщо
й воно недоступне — альтернативи: `mobiuslabsgmbh/faster-whisper-large-v3-turbo`.

## Русифікація («четыре пять» замість «чотири п'ять»)

Див. [Ukrainian Accuracy](Ukrainian-Accuracy.md). Коротко: перемкни
**Модель для української → uk-ft**, додай слова у **Словник**, за потреби
увімкни LLM-постобробку.

## Антивірус лається на застосунок

whspr ставить глобальний хук клавіатури (pynput) — для антивірусів це схоже на
кейлогер. Для особистого використання додай виняток. Для розповсюдження іншим
потрібен code-signing сертифікат.

## Немає звуку / не той мікрофон

whspr пише з системного мікрофона за замовчуванням. Зміни дефолтний пристрій
вводу у Windows (Параметри → Система → Звук). Перевір рівень — надто тихий звук
відсікається RMS-гейтом (знизь `rms_threshold` у налаштуваннях, якщо треба).

## Лог
