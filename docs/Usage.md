# Usage

## Основне

1. Запусти `whspr.lnk` (або `.venv\Scripts\python flow.py`).
2. Постав курсор у будь-яке текстове поле (браузер, месенджер, редактор).
3. **Тримай F9**, говори, **відпусти** — текст вставиться на місце курсора.
4. **F10** — перемкнути мову (укр ⇄ англ).

Хоткеї налаштовуються (див. нижче). Hold-to-talk = запис лише поки клавіша
натиснута, тож коротка пауза між фразами не проблема.

## Головне вікно

Відкривається кліком на іконку в треї. Закриття (✕) ховає у трей — застосунок
продовжує працювати. Правий клік на треї → **Вихід** для повного закриття.

### Головна (Dashboard)
- Живий статус: Готово / Запис / Розпізнаю.
- Статистика: слів сьогодні, диктовок сьогодні, слів усього, слів/хв.
- Кнопка мови, останні диктовки.

### Історія
Усі диктовки (з `history.db`). Кожна — час, мова, тривалість, текст.
**Копіювати** / видалити (✕) / **Очистити все**.

### Словник
- **Терміни** (через кому): імена, бренди, жаргон — передаються Whisper як
  `hotwords`, підвищують точність на цих словах.
- **Голосові команди**: `фраза = текст` по рядку. `\n` = новий рядок.
  Наприклад `новий рядок = \n`.

### Голосова пунктуація та числа
Два перемикачі в **Налаштування → Загальні** (обидва увімкнені за замовчуванням):

- **Голосова пунктуація** — сказані вголос знаки стають символами: «кома» → `,`,
  «крапка» → `.`, «знак питання» → `?`, «знак оклику» → `!`, «двокрапка» → `:`,
  «крапка з комою» → `;`, «тире» → ` — `, «три крапки» → `…`. Whisper часто вже
  ставить крапки й коми сам; це для випадків, коли ти диктуєш знак навмисно.
- **Числа цифрами** — числівники згортаються в цифри: «триста п'ятдесят два» →
  `352`, «дві тисячі двадцять чотири» → `2024`. Whisper робить це й сам, але
  нерівно — пас підстраховує. Поодиноке «один/одна» лишається словом (це радше
  артикль, ніж цифра). Читання року парами англійською («twenty twenty four»)
  поки не підтримується.

Якщо диктуєш текст, де ці слова потрібні буквально (наприклад, редагуєш вимову),
вимкни відповідний перемикач.

### Голосові команди
Замість друку тексту команда **редагує попередню диктовку**. Спрацьовує, лише
коли вся фраза — точна команда, тож звичайне диктування не сплутається. Діє на
останню вставку в тому самому вікні; якщо ти вже щось надрукував чи переставив
курсор — команда скасовується, а не псує текст не там.

Без LLM (детерміновані):
- **«великими літерами»** / «капсом» — ВЕЛИКІ
- **«маленькими літерами»** — маленькі
- **«з великої літери»** — Перша велика
- **«видали останнє»** / «скасуй» / «стерти» — прибрати останню диктовку

Потребують LLM (Groq або Ollama):
- **«переклади англійською»** / «переклади українською»
- **«перепиши формально»**
- **«коротше»** / «скороти»
- **«виправ помилки»** / «виправ граматику»

Розумні команди без увімкненого LLM ввічливо скажуть, що потрібен Groq/Ollama.

### Режим без утримання (hands-free)
За замовчуванням вимкнено. Увімкни в **Налаштування → Загальні → «Режим без
утримання»**. Тоді: **тап** клавіші вмикає запис, говори скільки треба, whspr
**сам зупиняється після ~1.5 с тиші** (або тапни ще раз). Зручно для довгих
диктовок. Поріг тиші адаптується до твого мікрофона; є стеля 60 с про запас.

Компроміс: у звичайному режимі (утримання) не буває випадкових зупинок посеред
паузи. Обирай що зручніше.

### Автовизначення мови
**Налаштування → Загальні → «Автоматичне визначення мови»**. Whisper сам
визначає українську чи англійську — не треба тиснути F10. Компроміс: для
детекції використовується універсальна stock-модель, тобто перевага донавченої
uk-ft втрачається. Для чистої української краще лишити вимкненим і uk-ft.

### Налаштування
Див. [Configuration](Configuration.md).

### Моделі розпізнавання
**Налаштування → Модель розпізнавання** — список усіх доступних моделей. Нічого
не вшито в застосунок: качаєте лише те, чим користуєтесь.

- **Завантажити** — тягне модель з Hugging Face, прогрес видно на кнопці.
- **Обрати** — робить завантажену модель активною (діє одразу, без перезапуску).
- **✕** — видаляє модель з диска. Активну видалити не можна: спершу оберіть іншу.

Розмір біля незавантаженої моделі — обсяг качання. У завантаженої показано
**реальне місце на диску**: воно більше, бо кеш Hugging Face тримає і blob-и, і
копії-снапшоти (на Windows без прав на символьні посилання — подвійний обсяг).

Що обрати: **Large v3 Turbo UA** для української, **Large v3** якщо потрібна
максимальна точність і не шкода швидкості, **Small**/**Base** для слабкого GPU.

## Свої клавіші та комбінації

**Налаштування → Клавіша диктовки → «Натисніть клавіші»** → натисни бажане:
- одну клавішу: `F9`, `Scroll Lock`, `Pause`…
- комбінацію: `Ctrl+Space`, `Alt+Shift+D`, `Ctrl+Alt+Q`…

Кнопка одразу показує підпис («Ctrl + Space»). Збережи — **діє миттєво**, без
перезапуску. Для комбо hold-to-talk означає: тримаєш **усі** клавіші — запис,
відпустив будь-яку — стоп.

> Клавіші зчитуються по **фізичному коду**, тож комбінація працює однаково на
> будь-якій розкладці (укр/англ/рос).

## Голосові команди

Промовлені фрази перетворюються на дію в тексті:

| Скажи | Вставиться |
|---|---|
| «новий рядок» / «з нового рядка» / "new line" | перенос рядка |
| «новий абзац» / "new paragraph" | подвійний перенос |

Список редагується у **Словник → Голосові команди** або в `config.json` →
`replacements`.

## LLM-постобробка (опційно)

За замовчуванням **вимкнено** (нуль зовнішніх запитів). Якщо увімкнути
(**Налаштування → LLM-постобробка**), текст після розпізнавання чиститься від
слів-паразитів і пунктуаційних помилок:
- **Groq** — хмара, безкоштовний tier, потрібен API key ([console.groq.com](https://console.groq.com)).
- **Ollama** — локально, потрібен запущений `ollama` з моделлю `qwen2.5:7b`.

Помилка LLM ніколи не губить текст — вставиться сирий варіант розпізнавання.
