# Roadmap

## Зроблено ✅

- Push-to-talk диктовка (укр/англ) на локальному Whisper GPU
- Вставка через буфер + Ctrl+V (фізична VK, незалежна від розкладки)
- Головне вікно (customtkinter): Головна / Історія / Словник / Налаштування
- Свої клавіші та комбінації (capture), зміна без перезапуску
- Історія (SQLite), статистика (слів/хв, диктовок)
- Словник (hotwords), голосові команди
- Опційна LLM-постобробка (Groq / Ollama)
- Анти-русифікація: `initial_prompt`, фільтр галюцинацій, автокапіталізація
- Дві укр-моделі з перемикачем (stock / uk-ft)
- Pre-roll буфер, повернення фокуса, трей, автозапуск, single-instance

## Плани

### Точність
- **NVIDIA Parakeet-TDT-0.6B-v3** — 6,79% WER на FLEURS uk, вбудоване
  автовизначення мови (не треба хоткей F10). Потребує NeMo/ONNX-інтеграції.
- Оцінити `Yehor/whisper-large-v3-turbo-quantized-uk` (потрібна CT2-конвертація).

### UX
- **Toggle-режим запису** — клац-старт / клац-стоп замість утримання клавіші.
- **Command mode** — голосове редагування («видали останнє речення», «великими»).
- **Whisper mode** — індикатор тихого диктанту.
- Прев'ю розпізнаного перед вставкою (опційно).

### Продуктивність
- **Вивантаження моделі з VRAM після простою** — звільняти ~2 ГБ, коли довго не
  диктуєш; вантажити назад на першу фразу.
- Оцінити RealtimeSTT для стрімінгового режиму.

### Дистрибуція (окремий трек)
- Інсталятор (PyInstaller + Inno Setup), онлайн ~300 МБ.
- CUDA-детект: качати CUDA лише за наявності NVIDIA, чесний CPU-fallback.
- Code-signing (обов'язково для публічного розповсюдження через хук клавіатури).
- Freemium-модель, якщо монетизувати: локальне безкоштовно, хмарний Pro-шар платно.

## Свідомо НЕ робимо

- **Context-awareness зі скріншотами** (як у Wispr) — для персонального
  інструмента overkill і ризик приватності.
- **Хмарна обробка за замовчуванням** — суть KuubWave у локальності.
