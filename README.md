# whspr — локальний клон Wispr Flow для Windows

Push-to-talk диктовка: тримаєш **F9** — говориш — відпускаєш — текст вставляється
в активне вікно. **F10** перемикає мову (укр ⇄ англ). Усе локально, на GPU, без хмари.

> Розпізнавання мовлення через локальний Whisper (faster-whisper / CTranslate2)
> на NVIDIA GPU. Нічого не йде в хмару, немає підписки, працює офлайн.

📖 Повна документація — у [Wiki](docs/Home.md).

---

## Встановлення з нуля

**Вимоги:** Windows 10/11 x64, Python 3.12, NVIDIA GPU (GTX 900+, ≥4 ГБ VRAM,
драйвер ≥525). Без NVIDIA працює на CPU, але повільно (~5–8 с/фраза).

```powershell
# 1. клон
git clone https://github.com/kuubek5/whspr.git
cd whspr

# 2. venv
python -m venv .venv

# 3. залежності (включно з CUDA-бібліотеками — системний CUDA Toolkit не потрібен)
.venv\Scripts\pip install -r requirements.txt

# 4. ярлик для зручного запуску (pythonw, без консолі)
.venv\Scripts\python make_shortcut.py

# 5. запуск
.venv\Scripts\python flow.py
```

Перший старт качає модель (~1,6 ГБ, з HuggingFace) — потрібен інтернет **один раз**,
далі все офлайн. Модель вантажиться ~4 с + прогрів (у фоні, вікно з'являється одразу).
Далі транскрипція ~0,5–1,5 с на фразу (RTX 3070, large-v3-turbo int8).

> **Pagefile має бути увімкнений.** При вимкненому — CUDA/pip падають з
> `mkl_malloc failed` / error 1455. Див. [Troubleshooting](docs/Troubleshooting.md).

## Запуск

Подвійний клік на **whspr.lnk** (створюється кроком 4; `pythonw` без консолі,
лог у `whspr.log`). Або `.venv\Scripts\python flow.py`. Headless без GUI: `--no-ui`.

## UI

- **Головне вікно** (customtkinter, темна тема): sidebar — **Головна** (статус,
  статистика, останні диктовки), **Історія**, **Словник**, **Налаштування**.
- **Пігулка внизу екрана:** 🔴 запис + таймер → «Розпізнаю…» → ✓ текст (або ✗).
- **Трей:** клік → відкрити вікно; ✕ на вікні → ховає в трей (не закриває).

## Функції (стисло)

- **Своя клавіша/комбо** — «Натисніть клавіші» у Налаштуваннях: F9, Ctrl+Space,
  Alt+Shift+D тощо. Hold-to-talk для комбо. Не залежить від розкладки. Діє одразу.
- **Історія** — усі диктовки в `history.db` (SQLite), копіювати/видалити.
- **Словник** — терміни через кому → Whisper `hotwords`, точніше розпізнавання.
- **Голосові команди** — «новий рядок» / «новий абзац» → переноси.
- **LLM-постобробка** (off за замовч.) — пунктуація/слова-паразити через Groq
  (free tier) або локальну Ollama `qwen2.5:7b`. Помилка LLM ≠ втрата тексту.
- **Дві укр-моделі** — `stock` (deepdml turbo) / `uk-ft` (skypro fine-tune,
  менше русизмів). Перемикач без перезапуску.
- **Анти-русифікація** — `initial_prompt` українською + фільтр галюцинацій +
  автокапіталізація речень.
- **Автозапуск**, **один інстанс** (mutex).

Детально про кожну — [Wiki › Usage](docs/Usage.md) і [Wiki › Configuration](docs/Configuration.md).

## Технічні рішення (і чому)

- **Модель:** `deepdml/faster-whisper-large-v3-turbo-ct2` — робоче CT2-дзеркало
  (оригінальне `Systran/...` репо на HF віддає 401).
- **Вставка через фізичну VK 0x56, не символ 'v':** на кириличній розкладці
  символ `v` не мапиться (`VkKeyScan → 0xFF`) і pynput Ctrl+V мовчки не спрацьовує.
  Фізична клавіша обходить це — незалежно від розкладки.
- **Без Silero VAD:** `import onnxruntime` на тестовій машині висить хвилинами.
  Замість — RMS-гейт тиші; push-to-talk і так гарантує мовлення в записі.
- **Pre-roll 500 мс** — кільцевий буфер пише звук до натискання, перше слово ціле.
- **Цільове вікно** запам'ятовується на момент відпускання клавіші (вставка не «втече»).
- **CUDA DLL з pip-коліс** — системний CUDA Toolkit не потрібен, шляхи в `flow.py`.
