# KuubWave — brand reference

Renamed from **whspr** (2026-09-16). Part of the **Kuub** product family (KuubMesh, KuubMill).

## Mark
- **Waveform-K**: a monoline voice waveform that resolves into the letter **K**. Source concept: `../kuubwave_marks-bw_20260916-1620.png` (concept 1).
- App icon = Waveform-K, coral on a charcoal squircle. Master: `kuubwave_master_1024.png`.

## Wordmark
- Lowercase geometric **kuubwave** with a wave-dot on the `b` (concept 5).
- `kuubwave_wordmark_transparent.png` (coral), `kuubwave_wordmark_white.png` (for dark bg).

## Palette (chosen: "Coral on Charcoal")
- Accent / coral: **#FF6B5E**  (recording / live = coral, carried over from whspr)
- Icon tile / charcoal bg: **#111318**
- Rejected alternates kept on record: aqua-teal #22D3B8 on navy #0B132B, blue/violet #2563EB/#7C3AED, cool-gray #D1D5DB on graphite #1F2937.

## Type
- UI font: **IBM Plex Sans** (bundled, offline; Latin + Cyrillic subsets with і ї є ґ).
- Mono: JetBrains Mono / Cascadia Code.
